# Vault Health Report Template

> Generated by vault-auditor.ts (Phase 0 autonomous audit)
> Read-only analysis. No vault files are modified.

---

## How to read this report

This report is generated by reading every `.md` file in both vaults and performing
pure computation (no LLM, no network, no writes). It identifies structural problems
in the knowledge base.

**Severity levels:**
- **Critical**: Broken links, near-duplicate content, missing directories — needs immediate attention
- **Warning**: Staleness, orphan files, low connectivity — should be addressed
- **Info**: Topic coverage gaps, low wikilink density — awareness

---

## Sections

1. **Summary** — one-table overview of all metrics
2. **Dead Wikilinks** — `[[target]]` that points to non-existent files
3. **Ambiguous Links** — `[[target]]` that matches multiple files
4. **Dead Directories** — directories claimed in index.md but near-empty
5. **Staleness Scores** — age-based decay ranking, per-category half-life
6. **Content Overlaps** — near-duplicate file pairs (>80% similarity)
7. **Cross-Vault Gaps** — topics present in one vault but missing from the other
8. **Topic Coverage** — 12 predefined topics, files in each vault
9. **Obsidian Wikilink Stats** — wikilink density and frontmatter usage

## Remediation Guide

### Dead Wikilinks
- For each dead link: either create the target file, or remove the link
- Priority: high-traffic files first (cron-B files are most-linked)
- Batch fix: `wikilink-resolver.ts` (Phase 1) can generate stub pages

### Dead Directories
- Create at least 3 files per claimed directory, OR
- Remove the directory claim from index.md, OR
- Lower the expected minimum for specialized directories

### Content Overlaps
- >95% similarity: likely duplicates — merge or remove one
- 80-95%: review manually — may be legitimate variants

### Staleness
- >60% stale: consider archiving or regenerating
- codebase/ files age fastest (14-day half-life) — these are snapshots, expected to age
- concepts/ and decisions/ age slowly (60-90 day half-life) — if stale, it's a concern

### Isolated Files
- Files with no outbound wikilinks — add at least 1-2 relevant links
- These files are "dead ends" in the knowledge graph

### Orphan Files
- Files with no inbound links from other files
- Are they still relevant? If yes, link to them from related pages.

### Cross-Vault Gaps
- High-severity gaps: essential topics missing from one vault
- Bridge by copying/symlinking key files between vaults, or
- Enable the Obsidian read bridge (Phase 4)

### Obsidian Wikilink Density
- Obsidian vault has rich content (442 files) but almost no wikilinks (3 files)
- This means the Obsidian vault is a flat file collection, not an interlinked wiki
- Fix: run wikilink backfill proposal (Phase 0, item 7)
