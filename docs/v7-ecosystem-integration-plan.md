## 核心目标

**让 Hermes Pro 具备外部工具操作、多 worker 调度和高级记忆算法能力。**

原 V4 计划（CLI-Anything / Ruflo / Mano-P / OpenHuman / Daily Digest）因各种原因未能在 2026-05-27 完成现状调查后实施。全部迁移到 V7，等前置条件满足后再推进。
