## Dynamic Class Whitelist Mechanism

CSS-only modifiers (`.active`, `.selected`, `.running`, `.stopped`, `.error`, etc.) used via
dynamic `className` concatenation are NOT in this list — they are detected as "in use" by the static
analyzer and correctly kept. This whitelist is only for full class names that appear in CSS but not
in any static string in TSX/TS source.

Rule for future audits:
- Class appears as static string → "in use" (keep)
- Class appears as template literal with `${}` → whitelist (keep)
- Class not found anywhere → candidate for removal
